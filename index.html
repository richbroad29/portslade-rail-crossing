ℹ️ How This Works
Uses the National Rail Live Departure Boards API for real-time train predictions at Portslade station. Barriers typically close ~2 min before a train arrives and open ~30 sec after. If two trains pass within 5 min, barriers may stay closed between them. Falls back to timetable data if the API is unavailable.
Estimates only · Not a safety system · Always obey signals & barriers
